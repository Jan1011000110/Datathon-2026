What came from us, not from the model

Barcelona holidays

  • The model handled holidays in general, but not the ones that only Barcelona has.
  • They are not in the training data, so validation said it was not worth adding them.
  • We know the campus closes on those days, so we added three dates: +0.23 on the public leaderboard.

The public / private split

  • Scores on the leaderboard were changing without the models getting better.
  • We did not find the reason ourselves, but we decided it was the important question and used our submissions to test it.

A wrong idea: corrupted data

We thought the private test had broken sensor data and prepared for it. We tested it, it was not true, and we dropped that work.

Questioning the model

We asked why each choice was made: why ridge regression, why 36 hours, what each feature does. One feature turned out to do nothing.

Is the signal public data?

We suspected price and CO₂ were Red Eléctrica’s public data and asked for a check. They are. We told the organisers and did not use it.

What counts as fair

Using the real test values: no. Filling the battery before the private half: yes, and the code says so.
