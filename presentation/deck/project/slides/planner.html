How we decide what the battery does

  • It is a linear program: minimise what we import from the grid in the next 36 hours, counting CO₂ and price with the 70/30 weights of the score.
  • We started with scipy’s LP solver. Then we wrote our own solver with dynamic programming. It does not discretise the battery level, so the result is exactly the same.
  • We do not plan on a single forecast. For demand and solar we plan on several possible values for the next hours.
  • Why: if we discharge more than the campus uses, the rest is given away for free. So when we are not sure, it is better to discharge a bit less.
