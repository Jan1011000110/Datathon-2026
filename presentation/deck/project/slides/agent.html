HOW IT WORKS

How the agent decides each hour

1 · FORECAST

What it cannot see

Price and CO₂ beyond three hours, the campus load and the solar output. Each forecast carries its own error distribution, measured on held-out weeks.

2 · PLAN

What a stored kWh is worth

An exact dynamic program over the next 36 hours and several possible futures. It discharges the next kW only if that is worth more now than later.

3 · ACT SAFELY

Never break a limit

The command is clamped to what the battery can physically do. If anything fails, two simpler agents stand behind it, then 0 kW.

Each hour the agent does three things. It forecasts what it cannot see, and each forecast comes with an error distribution measured on weeks the model did not train on. It then plans: an exact dynamic program gives the value of one more kilowatt-hour in the battery, over 36 hours and several possible futures. The rule is simple: discharge the next kilowatt only if it is worth more now than later, taking into account the chance that the campus cannot use it. Finally it acts safely: the command is clamped to the physical limits, and if any part fails, two simpler agents stand behind it. We had zero infractions in every submission. The run-time code uses numpy and pandas only.
