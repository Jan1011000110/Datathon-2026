What we predict and how

Campus demand

Model

LightGBM (300 trees) plus a few rules for the meter. It predicts the change from the last reading.

Features (28)

Hour, weekday, last 3 readings, same hour yesterday and last week, average of the last 3 similar days, temperature, a holiday indicator.

Result

Error for the current hour: 38 → 20 kW

Solar

Model

Ridge regression. It predicts how clear the sky is, compared to a clear-sky curve for that date.

Features

Clearness in the last hour, today so far and yesterday. Panel temperature minus air temperature.

Result

Error: 91 → 85 kW. LightGBM was worse here (151 kW)

Price and CO₂ after 3 h

Model

Ridge regression, one model per hour ahead. It predicts the difference from a typical day.

Features

The last 48 hours of the signal, the last 12 of the other one, and the typical value for that month, day type and hour.

Result

CO₂ error 3 hours ahead: 7.8 → 4.6 g/kWh

(about 30 s) For the campus demand we use LightGBM with 28 features: hour and weekday, the last readings, the same hour yesterday and last week, temperature and a holiday indicator, plus a few rules because the meter doesn't update at night. This cut the error in half. For solar we use ridge regression on how clear the sky is. LightGBM was worse there. For price and CO2, ridge regression on the last 48 hours.
